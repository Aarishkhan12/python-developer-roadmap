# 🐍 Python Developer Roadmap

**12 weeks from zero to hireable junior Python developer.**

A self-paced, project-based curriculum. Every week ends with a real deliverable. No fluff, just code.

## 📋 Curriculum

| Week | Focus | Deliverable |
|------|-------|-------------|
| 1 | Setup, variables, conditionals, loops, functions, lists/dicts | `task_logger.py` |
| 2 | Strings, collections, comprehensions | `expense_tracker.py` (CLI) |
| 3 | Files, JSON/CSV, errors, modules, venv | Expense tracker with file save/load |
| 4 | OOP (classes, inheritance, encapsulation) | `library_system/` |
| 5 | Git & GitHub | All projects pushed to GitHub |
| 6 | Clean code, type hints, pip, debugging | Refactored project |
| 7 | Decorators, generators, pathlib, datetime | File organizer script |
| 8 | Algorithms lite + LeetCode Easy | 10 Easy problems solved |
| 9 | Flask / web basics (HTTP, routes, templates) | Todo web app |
| 10 | SQL + SQLite + SQLAlchemy CRUD | Flask app connected to DB |
| 11 | pytest, unit tests, test coverage | Tested module (80%+ goal) |
| 12 | REST APIs, `requests`, FastAPI intro | REST API milestone project |

## ⏰ Daily Schedule

| Time (PT) | Activity |
|-----------|----------|
| 3:00 - 3:50 | Learn + type examples |
| 3:50 - 4:35 | Exercises / project work |
| 4:35 - 4:55 | Debug & test |
| 4:55 - 5:00 | Log takeaway |

**Mon-Thu:** Topic of the day + exercises  
**Friday:** Mini-project / milestone deliverable

## ✅ Rules

- A day is done only when code runs, not just reading
- Every Friday ships a working deliverable
- All code pushed to this repo by Week 5

## 🛠 Tech Stack

- **Language:** Python 3.11+
- **Web:** Flask, FastAPI
- **Database:** SQLite, SQLAlchemy
- **Testing:** pytest, coverage.py
- **Tools:** Git, venv, pip

## 🚀 Getting Started

```bash
# Clone this repo
git clone https://github.com/Aarishkhan12/python-developer-roadmap.git
cd python-developer-roadmap

# Set up a virtual environment
python -m venv venv
source venv/bin/activate  # or venv\Scripts\activate on Windows

# Start with Week 1
cd week-01-fundamentals
```
